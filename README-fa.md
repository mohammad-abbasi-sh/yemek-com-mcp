# yemek-com-mcp 🇹🇷

سرور MCP غیررسمی و **فقط‌خواندنی** برای **Yemek.com** — سایت دستور غذای ترکیه: جست‌وجوی دستورها، جزئیات کامل دستور (مواد، مراحل، زمان، تعداد نفرات، امتیاز)، دسته‌های ویژه، انتخاب‌های روزانه‌ی «Bugün Ne Pişirsem?» (امروز چی بپزم؟)، دستورهای ویدیویی و محبوب‌ترین دستورها.

> بخشی از «کارخانه‌ی MCP ترکیه» (پایپ‌لاین به سبک سپهر). هیچ وابستگی به Yemek.com ندارد.

## برای ایجنت‌های هوش مصنوعی

```json
{
  "mcpServers": {
    "yemek-com": {
      "command": "uvx",
      "args": ["yemek-com-mcp==0.1.1"]
    }
  }
}
```

## ابزارها

| ابزار | توضیح |
|------|-------|
| `yemek_search_recipes` | جست‌وجوی دستور با نام غذا یا ماده — `query`، ‏`limit` (۱ تا ۳۰) |
| `yemek_get_recipe` | دستور کامل — `slug` (مثلاً `mercimek-corbasi`) یا URL کامل yemek.com/tarif/... |
| `yemek_list_categories` | دسته‌های ویژه‌ی دستورها + تعداد دستور هر دسته |
| `yemek_list_trending` | انتخاب‌های امروز «Bugün Ne Pişirsem؟» (۱۵ دستور) |
| `yemek_list_videos` | دستورهای ویدیویی («Videolu Tarifler») |
| `yemek_list_popular` | محبوب‌ترین دستورها («Popüler Yemek Tarifleri») |

مثال (`yemek_search_recipes` / «mercimek»): ۵۳۳ دستور پیدا شد؛ اولین نتیجه «Lokanta Usulünde: 4 Kişilik Mercimek Çorbası» (آماده‌سازی ۱۵ دقیقه). مثال (`yemek_get_recipe` / «mercimek-corbasi»): ۶ نفره، مجموع ۶۰ دقیقه، امتیاز ۴٫۳ (۲۳۰ رأی)، ۱۲ ماده، ۸ مرحله.

نکته‌ها:
- نتایج جست‌وجو در هر درخواست ۳ دستور برمی‌گردانند — سرور خودکار صفحه‌بندی می‌کند.
- زمان‌ها ISO 8601 (`PT60M`) یا مخفف ترکی (`15dk`) هستند؛ تعداد نفرات به ترکی است (`6 kişilik`).
- داده: صفحات عمومی yemek.com + JSON عمومی جست‌وجو — بدون لاگین، بدون کلید، فقط‌خواندنی.

## قوانین

غیررسمی و فقط‌خواندنی — بدون لاگین، بدون کلید، بدون نوشتن. تست‌ها: آفلاین با فیکسچر + تست زنده (۲۰/۲۰ سبز).
